# Project videos

Walkthrough films of four portfolio builds, served as a static page at https://bryanacevedo.github.io/project-videos/.

| Film | Length | Code | Live demo |
|---|---|---|---|
| Account Desk | 2:01 | [account-desk](https://github.com/bryanacevedo/account-desk) | [account-desk-x4ko.onrender.com](https://account-desk-x4ko.onrender.com) |
| Events Desk | 3:41 | [events-desk](https://github.com/bryanacevedo/events-desk) | [events-desk.onrender.com](https://events-desk.onrender.com) |
| CRM Desk | 1:36 | private | [crm-desk-sevh.onrender.com](https://crm-desk-sevh.onrender.com) |
| Market Desk | 1:52 | [market-desk](https://github.com/bryanacevedo/market-desk) | [market-desk-3kou.onrender.com](https://market-desk-3kou.onrender.com) |

Each film is made with HyperFrames from the app's real screens running its demo: invented companies and people, with every outside service simulated. The voices are text-to-speech run locally, and the music is from Pixabay under the Pixabay Content License.

The live demos are redeployed by hand, so they can run behind the code and the films.

## What is here

- `index.html`: the page with the four films.
- `privacy.html`: the privacy policy for Events Desk's Google sign-in.
- `video/`: the films (MP4) and their posters.
- `.nojekyll`: GitHub Pages serves the files as they are.

Nothing is built here. The films are rendered elsewhere and committed as finished files.
